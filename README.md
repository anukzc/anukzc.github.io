# anukzc.github.io

Personal website of Anuk Centellas, a graduate student in Computational Linguistics at the University of Washington.

**Live site:** https://anukzc.github.io

## About

A single-page static site covering my background, research and work experience, projects, resume, and contact information. It is hosted with GitHub Pages and has no build step.

## Structure

```
.
├── index.html        # The whole site
├── assets/
│   ├── css/          # Compiled styles (main.css) and Font Awesome
│   ├── js/           # jQuery and theme scripts for scrolling and nav highlighting
│   ├── sass/         # Theme source styles
│   └── webfonts/     # Font Awesome icon fonts
└── images/           # Headshot, background image, and linked PDFs (resume, papers, poster)
```
